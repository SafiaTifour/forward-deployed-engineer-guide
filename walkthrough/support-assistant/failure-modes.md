# Failure modes

## Common failure modes
- retrieval returns the wrong policy version
- policy is missing or outdated
- user request is ambiguous
- the system guesses rather than escalating
- a malicious or confusing instruction is embedded in a document
- the model outputs a response without adequate citations

## Response posture
In each case, the preferred response is to state the limitation, ask for review, or refuse the action when required.

## Why this matters
The system should be designed to fail safe, not to appear confident when the evidence is insufficient.
